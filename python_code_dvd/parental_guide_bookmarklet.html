Elternleitfaden-Bookmarklet

IMDb blockiert automatische Abrufe. Mit diesem Lesezeichen speicherst du den Elternleitfaden eines Films direkt aus deinem Browser, während du die IMDb-Seite ansiehst.

🎬 IMDb → Sammlung

Den gelben Button mit der Maus in die Lesezeichenleiste ziehen (Leiste einblenden: Strg+Umschalt+B). Falls das nicht klappt: „Code kopieren“, ein neues Lesezeichen anlegen und den Code als URL einfügen.

So geht's

  1. Öffne auf IMDb die Seite eines Films und klick das Lesezeichen: Es wechselt zum deutschen Elternleitfaden, z. B. imdb.com/de/title/tt0118715/parentalguide/.
  2. Dort klickst du das Lesezeichen noch einmal. Es lädt imdb_parental_guide_tt….json in deinen Download-Ordner: MPA-Begründung, die fünf Stufen und je Kategorie die ersten (max. 5) Kommentare ohne Spoiler.
  3. Wenn du ein paar Filme gesammelt hast, übernimmst du sie in die Sammlung:
    python python_code_dvd/import_parental_guides.py
    Das Skript verschiebt die Dateien nach metadata_parental_guides_dvd/ und baut die Website-Daten neu. Danach wie gewohnt committen und pushen.
